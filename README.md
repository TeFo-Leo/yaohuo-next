# 妖火 · Next

妖火论坛的浏览器增强脚本，功能自选、配置全本地。

> **发行版**：`yaohuo-next-gf.user.js`（GreasyFork 版）、`yaohuo-next-sc.user.js`（ScriptCat 版）——两版代码完全一致，仅脚本头信息中的主页/更新地址不同，按你使用的脚本管理器选一个安装即可。

打开设置面板：点悬浮入口的「设置」按钮，或随时按 **Alt + ,**。

## 浏览增强

### 帖子悬浮预览

在任意地方鼠标悬浮帖子链接（帖子内、回复区的链接也可以）即可打开帖子预览框，不跳页就能预览正文，支持图片、视频、Markdown 帖的标题层级。

### 用户名片

点击用户名（或@的用户名），链接旁弹出资料卡：头像、在线状态、等级妖晶等统计、签名档一屏看完；底部「私信」直达发信页，「进入主页」新窗口打开完整资料页。

![用户名片](https://tc.qdqqd.com/file/BQACAgUAAyEGAASI5yFpAAINrmr2wVrE-_spRLMQhWkNe0DTVViPAAJmIgACKwG4VxXJX5NDSRtbPQQ.png)

### 回复复读机

每条回复右侧多一个「+1」，点一下对方的内容（文字、图片、链接）就转成 UBB 填进回复框并自动发送（可关掉自动发送，改为只填充）。

![回复复读机](https://static.eeo.cn/upload/images/20261113/495386f1ffda16481553.png)

### 自定义打赏金额

打赏面板里追加一个自定义格子，想打多少填多少，不受预设档位限制。

![自定义打赏金额](https://static.eeo.cn/upload/images/20261113/93cfcc4a3aa0de5c1172.png)

### 首页搜索类型

首页搜索框前面加一个搜索类型下拉，可以根据不同类型搜索。

![首页搜索类型](https://dc-file.leanticket.cn/VPQJ9tn2ulWzoFyXWqagFog3m3chV9qd/rvpAhG9Z.png)

### 关键词屏蔽

列表页每个帖子标题旁有一个小盾牌按钮，点击直接把该帖标题带入输入框，添加关键词即可屏蔽。命中处理两种模式：

- **模糊遮挡**：帖子整条模糊，遮挡层显示命中的关键词，不可点击；可「临时解除」这一条（本次会话有效）。永久解除请手动删除关键词。
- **直接隐藏**：帖子直接消失，每页过滤完成后提示按哪些关键词各过滤了几条。

关键词在标题旁弹窗和设置面板两处共享，改动实时生效。

![关键词模糊遮挡](https://everywhere-cloud.oss-cn-shanghai.aliyuncs.com/chat/1794554957/FUS6SHeA.png)

### 跳过外站跳转提示（默认关闭）

开启后点击外站链接不再经过「跳转安全提示」中转页，直接落到中转页上也会立刻跳走，不往历史记录里塞中间页。

![外站中转页（开启后跳过）](https://everywhere-cloud.oss-cn-shanghai.aliyuncs.com/chat/1794554965/RbguweBR.png)

### 自动吃肉（默认关闭）

**【谨慎开启！！！】**打开肉贴（页面带剩余次数的帖子）时自动回复一个吃肉词，**当日每帖只吃一次**；自己的回复里已经有「吃/肉」或剩余次数为 0 时不会动作，普通帖子完全不受影响。

吃肉词可以在设置面板里自由增删（预置：吃、肉、吃吃、吃吃吃、肉肉、吃。系列、肉。系列、7、77、777、+30）；自动记住上次用过的词，**下一次不会重复**，同一个词要隔一轮才会再次轮到。提交成功后页面会显示「🤖 已自动吃肉」标记。

由于常年没有肉贴，只能借鉴（**抄袭**）这个老哥的脚本了。[妖火网增强插件总结 - 资源共享](https://www.yaohuo.me/bbs-1570869.html)

## 编辑器增强

### 自定义表情

表情面板新增「自定义」分类：粘贴图片链接或上传本地图片即可添加，点表情直接插入 `[img]` 代码。列表里每张表情右上角有常驻删除角标，点击弹窗确认后删除；任何增删，身后的表情面板都实时刷新。

![自定义表情与删除角标](https://qn.fqcdn.cn/666666666666666666666666/20261113153017855159-vip.png)

### 一键收藏表情

帖子里的内容图片右下角常驻一个「+」按钮（桌面、移动端都能直接点），点一下就收进自定义表情。头像、表情框里的图、编辑器里的图、过小的图标都不会触发；最小触发尺寸可调。

![图片右下角常驻收藏按钮](https://xiuxiu-pro-new.meitudata.com/ai_quality/e78ef2f58e5b7b9ce62845d24ddf2cec.png)

### 粘贴自动上传

在回复框里直接 **Ctrl+V** 图片或视频：自动上传图床并在光标处显示进度占位符，完成后回填 `[img]` / `[movie]` 代码并渲染出来，失败则移除占位符并提示。

### UBB 渲染

输入框里的 `[img]`、`[url]` 不用提交就能看到实际效果，图片和链接直接渲染在编辑器里，右下角小图标可弹窗修改信息。

![UBB 就地渲染](https://everywhere-cloud.oss-cn-shanghai.aliyuncs.com/chat/1794554943/BNrwg2nS_vip.png)

## 其他

- **数据本地保存**：所有配置、自定义表情、屏蔽关键词都存在本地，没有任何外部上报。
- **移动端适配**：各弹层自适应窄屏。
- **深色主题**：所有界面跟随站点的浅色 / 深色 / 跟随系统三种主题。
- **总开关与独立开关**：每个功能都可以单独关闭；关闭插件总开关立即停用全部功能，且各功能开关状态原样保留。
- **功能排序**：设置面板里每个功能左侧有 ⠿ 手柄，拖动即可调整顺序（带整卡虚影、插入位置提示线，拖到面板边缘自动滚动），顺序自动记住；没有分组限制，想怎么排就怎么排。
- **快捷键**：`Alt + ,` 随时打开设置面板。
